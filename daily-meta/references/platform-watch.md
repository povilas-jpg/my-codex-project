# Meta platformos pokyčių žurnalas (platform-watch)

WATCH režimas (1× mėn.) papildo šį failą naujais datuotais įrašais VIRŠUJE.
Formatas: `- {pokytis} → {ką tai reiškia mūsų klientams}`. Tik pokyčiai, liečiantys
LT smulkų verslą (lead gen, skambučiai, mažas e-com, awareness). Šaltinių prioritetas:
Meta oficialūs > ppc.land > jonloomer.com > kiti.

## 2026-07 (seed iš research digest'o)

- **Andromeda** pilnai veikia: kūrybų įvairovė = targetingas; near-duplicate variantai
  suspaudžiami → rekomenduojam skirtingus konceptus, ne perspalvintus variantus. Vizualų
  gyvavimo ciklas BIG tier ~2–4 sav.
- **Atribucija 2026-01-12**: nebeliko 7d/28d view langų (max 1d view) → view-heavy accountų
  reported konversijos krito 15–30 %. Palyginimai per šią ribą — su pastaba.
- **Atribucija 2026-03**: „clicks" = tik link clicks; likes/shares/comments → naujas 1d
  engage-through bucket. Default: 7d click / 1d engage / 1d view. Skeptiškiems klientams
  rodyti click-only.
- **Flexible Format pašalintas iš ad setup (2026-03)** → „Flexible media" toggle Advantage+
  creative viduje. Senų flexible ads neredaguoti — dublikuoti.
- **Threads placement** default-on nuo 2026-01-21 (Advantage+ placements) → tikrinti placement
  breakdown; CPM pigus, konversijų kokybė neįrodyta.
- **Existing Customer Budget Cap pašalintas** → ASC be exclusions linksta į esamus pirkėjus;
  workaround: savaitinis customer-list exclusion arba audience segments.
- **Offline Conversions API mirė 2025-05** → CRM eventai tik per CAPI.
- **Opportunity Score** — matuoja rekomendacijų priėmimą, NE performance; rinkti lengvus
  taškus, ignoruoti tai, kas resetintų learning.
- **Ads Manager rodo oficialų „safe increase"** biudžeto skaičių per ad setą → naudoti vietoj
  aklos 20 % taisyklės, kai rodomas.
